# code/ 目录 AI 入口

本仓库团队 AI 协作规则以根目录 `../AGENTS.md` 为唯一事实来源。在 `code/` 下工作时，先遵守根规则；本文件只保留给仍会查找 `code/AGENT.md` 的旧流程作为兼容入口。

## code/ 目录补充

- 前端位于 `sewpg-bid-frontend/`，后端位于 `sewpg-bid-backend/`。
- Skill 位于 `sewpg-bid-backend/opencode/skills/<skill-name>/`。
- 本地运行入口在当前目录，可按任务需要使用 `docker compose up -d --build`。
- 技术标、商务标和共享底座的修改边界以根 `AGENTS.md` 为准。
