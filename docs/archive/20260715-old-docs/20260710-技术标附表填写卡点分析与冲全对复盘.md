## 三、三轮攻坚做了什么（07-08 ~ 07-10）

1. **OCR 链路打通**（129e4cc）：证书 PDF 三处断层修复——后端 PDF 下载放行 +
   OCR sidecar 生成（DeepSeek-OCR，共享缓存跨缺口复用）；table-filler 四路抽取
   （冒号键值/markdown 表格/机构名/领域正则，全部 partial 高亮待人工）；
   F 系列证书意图过滤/证书权威化/PROJECT_SPECIFIC 豁免。F 系列 230 字段从
   0 → 154 带值。附带修掉 H.5 运输表路径被"大部件"词面误触发整表重建 F.3
   的假阳性（曾虚报 66 格 passed）。
2. **机型双列镜像**（81aaef9）："认证机型N/投标机型N"成对列同值复制
   （F.2.1 金标 11→22/48）。注意：**部件类不能镜像**——金标证实认证叶片（中车）
   与投标叶片（中材）厂家不同。
3. **输出规范化 + 派生 + 行键路由**（625f640）：纯单位串/纯量词不作答案值
   （修 'kg/m3' 抄进格、A.1 台数被"台"垃圾候选冲突误杀）；字段名内嵌单位剥离
   与量纲换算（17.8T→17.8、14.4T+kg 列→14400）；尾星号剥离；扫风面积几何派生
   （π×110²=38013）；doc 表格同行第二数值对；F.3 行键路由（行组锁部件，
   发电机证书厂家不再窜进叶片行，F.3.1 31 格填上行内合理值）。
4. **评分器 v5 + 需求单**（3c268ac）：三类等价容差（空响应 / 换行分隔 /
   数字格式），v4/v5 双口径同报告；素材补录需求单成文（已并入本文 §七）。

守护纪律：每轮改动跑 81 项全量批量 + 金标逐格评分，**三轮均零回退**；

### 2. 人工决策格（~30 格）——不该自动填，卡在产品形态

- 商务承诺类：F.2.3/F.4.2 的"已完成 / 本项目第一台风电机组交货前 / 无待解决项"
  ——自动填等于替投标人做交付承诺；
- 投标人自主选择：F.3.1 认证部件（中车）vs 投标部件（中材）用哪家。

正确出路是**前端"建议值 + 一键采纳"**：AI 给出候选与证据，人点确认。当前
`technicalGapRecognitionHelpers.js` 的质量警示（resultSummaryForItem）仍是死代码，
qualityStatus=needs_review 在界面无感知——用户看不到哪些格待确认。这是技术标
前端的一轮独立工作。

### 3. 金标自身漂移（~30-50 格）——评测认识论

中标人加行（C.1 插入"机组安全设计等级"行、B.2 加"二、易耗品部分"组标题）、
改行标签（C.3 拆"主轴轴承类型及数量"）、改表头（G.5.x/E.1 措辞）。招标使用
说明明确"附表不得修改"，按模板填是合规行为，这些格不应计为我方错误。
待做：评分器加"结构漂移格"标记单列（v5 预留，未实现），把它们从"真错"
里透明摘出。

### 4. 映射/表述长尾（~150-180 格）——代码可磨但单点 ROI 低

- 同义表述：铸件 vs 铸造机架、GFRP&CFRP vs CFRP+GFRP（语义同、词面异）；
- 区间拆分：证书"运行风速范围 3~23m/s"拆到切入/切出两格；
- 多列备注行：B.1.1 备注列长文本；
- 数值口径：A.1 期望 kW 值（10,000）与容量 MW 惯例（10）冲突；
- 塔架重量求和派生（分段 75136+86510+… = 509632kg ≈ 509.632T，可做，值 1-2 格）。

每项都是独立小根因；建议攒到有明确批量收益时再做，避免为单格写规则。
