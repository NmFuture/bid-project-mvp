# 需求梳理

## 1. 当前目标

最终系统要支持技术标和商务标。当前先做商务标，把商务标端到端跑通。技术标后面单独梳理。

商务标现在的重点不是页面，而是 Skill、素材库、项目事实表和人工审核。

## 2. 商务标主流程

```text
智能解析
-> 投标判断
-> 建项目
-> 生成目录
-> 目录审核
-> 素材匹配
-> 素材和填写审核
-> 生成正文
-> 在线共创
-> 格式处理
-> 导出 Word/PDF
```

产品视角下，建项目发生在解析完成且人工确认参与投标之后。解析页展示为“上传招标文件并解析”，不强调“先新建项目”；如果后端短期需要一个临时承载记录保存上传文件和解析结果，这是技术实现细节，不作为正式投标项目暴露。

解析完成后人工决定是否参与：

- 参与投标：补齐项目身份信息，解析结果绑定到正式项目，后续目录、素材匹配、事实表都基于这个项目。
- 不参与投标：删除临时承载记录，不进入项目总览，不继续占用素材库和工作区。

上述解析入口口径同时适用于商务标和技术标；本轮需求细化仍以商务标端到端为主。

## 3. 每一步要做什么

| 环节 | 核心需求 |
| --- | --- |
| 智能解析 | 前端展示的结构化字段替换为：项目名称、招标编号、招标人、招标代理机构、递交截止时间、投标人资格要求、投标人须知前附表、商务废标项、商务评分细则。商务废标项重点识别包含“否决”的条款和打星号条款（★）。解析能力仍要保留 Word 内容提取、附件空表提取和待填写 Word 提取，供后续 AI填写使用。 |
| 投标判断 | 解析完成后由人工判断是否参与投标；不参与则删除临时承载，参与才进入建项目和后续流程。 |
| 建项目 | 只对确认参与投标的项目补齐身份信息，并把解析结果绑定到项目，后续目录、素材、事实表都基于这个项目。 |
| 生成目录 | 调用目录 Skill 生成商务标目录。现在效果不好，需要优化。 |
| 目录审核 | 人工确认目录，审核后的目录才进入素材匹配。 |
| 素材匹配 | 按审核后的目录去商务素材库、共用业绩库和项目材料里找素材。 |
| 素材和填写审核 | 人工逐条检查素材和 AI填写结果，错了可以改、换、上传或覆盖。 |
| 生成正文 | 用审核后的目录、素材、填写结果和项目事实表生成商务标正文。现在正文拼接 Skill 还比较粗。 |
| 在线共创 | 用 OnlyOffice 编辑，支持 AI 辅助修改。 |
| 格式处理 | 调用格式 Skill 整理 Word 格式。这个 Skill 需要重点优化。 |
| 导出 | 导出 Word/PDF。 |

## 4. 素材匹配的三种处理方式

处理方式只保留三类：

| 处理方式 | 含义 |
| --- | --- |
| 固定素材 | 素材库里有，可以直接拿来用。 |
| AI填写 | 有表格或 Word 需要填写，调用 Skill 根据项目事实表和输入文件完成填写。 |
| 人工补充 | 系统找不到，也无法自动生成，留给人工上传或填写。 |

人工指定不属于处理方式统计。它是 AI 匹配不准时，人工手动指定正确素材的纠偏动作。

## 5. 项目事实表

项目事实表是后面填写表格、填写 Word、生成正文都要读取的基础数据。

事实表可以由 Skill 或固定脚本生成，来源包括：

- 招标文件解析结果。
- 商务素材库。
- 共用业绩库。
- 人工补充的信息。

字段先按项目名称、招标人、投标人、项目地点、项目规模、报价、工期、资格条件、承诺、附件要求、业绩引用等方向设计。

## 6. 素材库

素材库分三类：

| 素材库 | 用途 |
| --- | --- |
| 技术标素材库 | 技术标专用，后续单独梳理。 |
| 商务标素材库 | 商务标专用，放资质、证书、授权、承诺函、报价说明、商务附件等。 |
| 共用素材库 | 技术标和商务标都能用，第一阶段重点是业绩库。 |

素材库需要支持上传、清洗、预览、标签、Wiki、检索和权限范围控制。

素材要支持多个标签。标签用来缩小 Skill 查找范围，提高匹配准确率。

当前素材清洗和 Wiki 生成效果都不够好，需要继续优化对应 Skill 或脚本。

## 7. 共用业绩库

共用业绩库不是简单文件夹，而是：

```text
PostgreSQL 存业绩字段和文件路径
+
对象桶存每条业绩对应的 Word 文件
```

业绩字段可以包括业绩名称、客户、项目类型、规模、地点、时间、金额、机型、标签、适用标类、权限范围、Word 文件路径、清洗稿路径、审核状态等。

商务标用它做业绩清单、资格证明、评分响应和附件材料。技术标后续可以用它做项目案例和方案经验。

## 8. 需要重点做好的 Skill

| Skill 能力 | 用途 |
| --- | --- |
| 商务标解析 | 前端展示字段按项目名称、招标编号、招标人、代理机构、递交截止时间、资格要求、须知前附表、商务废标项、商务评分细则收口；解析链路仍保留附件空表和待填写 Word 提取。 |
| 商务目录生成 | 生成可审核的商务标目录。 |
| 素材匹配 | 按目录、标签、权限和事实表找素材。 |
| 项目事实表生成 | 生成后续填写和正文要用的事实数据。对应新增 Skill `bid-business-fact-table-builder`。 |
| AI填写 | 填写空表和待填写 Word。 |
| 正文生成 | 把审核后的素材拼成商务标正文。 |
| 格式处理 | 整理最终 Word 格式。 |
| 素材清洗 | 把上传文件处理成可检索、可引用的素材。 |
| Wiki 生成 | 给素材生成可用于匹配的说明。 |
