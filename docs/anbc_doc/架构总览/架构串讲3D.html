操作说明 · 自由视角与快捷键

左键拖拽环绕旋转（自由视角）
右键拖拽平移视角（自由视角）
滚轮缩放（自由视角）
WASD前后左右平移（自由视角）
Q/E 或 R/F下降 / 上升（自由视角）
Shift按住加速移动
方向键自由视角下＝前后左右平移；导览模式下 ←/→ ＝ 上一站 / 下一站
触屏单指旋转 · 双指缩放
空格播放 / 暂停
H隐藏 / 显示全部界面文字（截图、投影用）
F全屏切换（自由视角下 F 仍是下降）
⟳ 自转地图缓慢自转开关（导览模式）

开启「自由视角」后相机由你接管；点击站点圆点、上/下一站或播放，会自动回到固定的全局俯视图——导览模式切站只点亮相关节点与连线，镜头不动。
