# 值得留下来的内容

> 旧文档已归档到 `doc/archive/2026-05-26-old-docs/`。当前判断只看本目录下 4 个文档。

## 1. 项目定位

本项目是一套面向技术标和商务标的 AI 投标辅助平台。

核心价值不是“让 AI 一次写完整标书”，而是把招标文件解析、资料匹配、正文生成、在线编辑、终稿导出这些环节串成可复用流程，减少人工复制、查漏、填表和排版成本。

## 2. 当前已形成的基础

- 已有 React 前端、FastAPI 后端、OpenCode/Skill、OnlyOffice、PostgreSQL、Redis、MinIO 的 Docker Compose 架构。
- 技术标和商务标已经有独立入口、独立页面、独立 API、独立 service、独立 Skill 和独立素材/Wiki 方向。
- 素材库、Wiki、审计、设置、登录、默认模板、OCR/图片解析等基础能力已经接入。
- 当前代码可以用 Docker Compose 启动，已有健康检查和基础冒烟记录。

## 3. 必须保留的产品边界

- AI 结果必须经过人工审核，尤其是承诺、报价、资格、证据、签章和最终投标文件。
- 技术标和商务标可以共享登录、部署、数据库、对象存储、基础组件，但业务链路要分开。
- 素材库要区分通用素材、客户素材、项目素材，避免跨客户、跨项目误用资料。
- 私有化部署、数据本地保存、模型网关可替换，是对外交付的重要边界。

## 4. 当前最重要的未完成项

- 真实技术标样本端到端验收。
- 真实商务标样本端到端验收。
- 技术标附表、待填 Word、证据链和格式导出的可交付质量。
- 商务标资格、承诺、否决项、业绩和评分索引的真实样本验证。
- 后端生产级权限：角色、工作区、项目类型三层校验。
- 字段维护表、业绩共享、三级目录加标签检索、混排机型、部署监控和一键启停。
