# 需求梳理

## 1. 最终目标

交付一套可私有化部署的 AI 数智化投标平台，支持技术标和商务标从招标文件导入到终稿导出的主要工作。

## 2. 核心流程

```text
招标文件导入
-> 智能解析
-> 目录与模板
-> 素材匹配与缺口处理
-> 标书生成
-> 在线共创
-> Word/PDF 导出
```

## 3. 技术标需求

- 解析招标文件中的项目基础信息、评分点、技术要求、附表和关键承诺。
- 根据招标文件、模板和素材库生成投标文件目录。
- 匹配通用、客户、项目三类素材。
- 填写附表和待填写 Word，无法确定的内容必须提示人工处理。
- 生成技术标正文并支持在线编辑、格式处理和导出。
- 保留证据来源，便于人工复核。

## 4. 商务标需求

- 解析商务评分、报价评分、符合性审查、资格条件、承诺条款和附件模板。
- 处理附件 7、附件 7I、附件 9 等商务响应材料。
- 识别否决项、符合性风险和需要人工确认的承诺。
- 匹配资质、业绩、财务、证书、授权、保证金等商务素材。
- 支持商务标正文生成、在线共创、格式处理和导出。
- 商务结果必须人工复核，不能自动替代法务或商务终审。

## 5. 素材库需求

- 区分技术标素材和商务标素材。
- 区分通用素材、客户素材、项目素材。
- 支持文件上传、清洗预览、Wiki 构建、附件管理和检索。
- 支持业绩共享和标签化检索。
- 避免跨客户、跨项目、跨标类误用素材。

## 6. 权限与部署需求

- 支持技术标人员、商务标人员、项目统筹人员三类角色。
- 前端可见性和后端接口授权都要按角色控制。
- 支持内网 Docker Compose 部署。
- 支持客户内网模型网关或可替换模型配置。
- 支持操作日志、系统设置、健康检查和基础运维能力。

## 7. 客户新增需求

- 解析字段维护表。
- 业绩表共享。
- 三级目录加文件标签二维检索。
- 混排机型标书撰写。
- 部署服务器监控。
- 一键启停。

## 8. 待确认问题

- 字段维护表由客户提供还是系统内配置。
- 商务标附件映射是否按客户模板可配置。
- 混排机型的事实表和素材筛选规则。
- 生产权限是否需要接入企业统一身份系统。
- Word/PDF 格式验收采用自动规则、人工抽检，还是两者结合。
